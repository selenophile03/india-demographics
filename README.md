# India Historical Demographic Pipeline (1947 - 2026)

This repository holds historical data and python pipelines monitoring Live Births, Total Deaths, and Infant Mortality Rates (IMR) across Indian States.

## Repository Setup
1. Install localized dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Compute analytical breakdowns:
   ```bash
   python scripts/analyze.py
   ```
3. Compile static visualization charts:
   ```bash
   python scripts/visualize.py
   ```
